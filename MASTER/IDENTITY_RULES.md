# IDENTITY RULES — 顔固定の絶対ルール

**このプロジェクトの最優先事項は、6人が「どのシーンでも同じ人物に見えること」。**
見た目の豪華さより、キャラクターの一貫性を優先する。

## 1. 絶対ルール

1. **新しい顔を作らない。** 生成時は必ず、そのキャラの `master_face/*_face_v1.png` と
   `character_sheet/*_sheet_v1.png` を参照する
2. **「新しいシーンだから新しい顔を作る」は禁止**
3. **「衣装変更＝人物変更」と解釈しない。** 衣装を変えるときは衣装だけを変える
4. 表情だけを変えるときは表情だけ、背景だけを変えるときは背景だけを変える
5. 迷ったら `characters/0X_*/[[IDENTITY_LOCK]]` を読む。**記述と画像が食い違ったら画像が正**

## 2. 維持する要素（変えてはいけない）

顔の骨格 / 輪郭 / 顔の縦横比 / 目の形 / 目の位置 / 眉 / 鼻 / 口 / 唇 / 顎 / 頬 /
年齢感 / 基本的な肌印象 / **髪の色**

## 3. 変えてよい要素

衣装 / アクセサリー / 髪型のアレンジ（結ぶ・まとめる）/ ポーズ / 表情 /
背景 / 構図 / 季節 / シーン / 照明

## 4. マスター画像の保護

- オーナーが「これで決定」とした画像は **MASTER / APPROVED / LOCKED** として扱う
- **上書き禁止。** 新しい画像を作っても旧マスターを消さない
- 変更するときは `_v2` として**新しいバージョンで保存**し、旧版は残す
- 台帳（`management/[[ASSET_INVENTORY]]`）から行を消さない

## 5. 巻き戻り防止

新しいセッションで古い資料と新しい資料が衝突したら、**最新の APPROVED / LOCKED を優先する。**

「名前未確定」「顔未確定」「6人を作り直す」という記述は**2026-09-01 時点ですべて古い**。
現在は 6人・名前・年齢・顔がすべて確定済み。過去の記述は履歴としてのみ扱う。
