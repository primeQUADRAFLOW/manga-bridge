| 名前 | 理由 |
|---|---|
| まお | 旧設定／他プロジェクト（AI美女）と混線するため |
| れい | 同上。**旧版シートで ID06 に使われていた**（現在は沙耶） |
| ひまり | 旧設定 |
| とき | 旧設定 |
| ひな | 旧設定 |
| みずき | 旧設定 |
| **みさき / 美咲** | **旧設定・生成ミス由来。特に再利用禁止。** 旧版シートで ID03 に使われていた（現在は優花） |

## 旧版シートについて

- **これは履歴であって現在状態ではない。** 名前の出典として参照しない
- 旧版では 03=美咲 / 04=紫 / 06=れい だった。**現在は 03=優花 / 04=りん / 06=沙耶**
- 旧版に書かれている「顔の特徴」テキストは参考になりうるが、**現在の顔マスターとの一致は未検証**。
