# CHATGPT INBOX — キュウチャから戻ってきた内容を入れる場所

**使い方**: キュウチャの回答を**要約せずそのまま**下の「受信」に貼る。
ピックが確定／未確定に仕分けし、確定候補は `canon/_proposed/` を経てオーナーの承認へ回す。

**ピックはここの内容を勝手にCANONへ昇格させない。**
オーナーの承認（`management/APPROVALS.log` への追記）を経て初めて確定になる。

## 書き方（1件 = 1ブロック）

```markdown
### IN_xxx | YYYY-MM-DD | 議題

**種別**: 設定案 / 画像採用 / 修正 / シート完成 / 名前変更 / 新ルール
**対象**: 例) 06 沙耶 / 全体

（キュウチャの回答をそのまま貼る）

**ピックの仕分け**
- 確定候補:
- 未確定（要検討）:
- 却下（理由）:
```

画像は貼らずに、所定のフォルダへ入れてから `python tools/inbox_ingest.py` で取り込む。
取り込むと台帳に Asset ID が付き、ここからはそのIDで参照できる。
