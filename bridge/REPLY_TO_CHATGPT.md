### 何が問題か

| | 優花(03) | 沙耶(06) |
|---|---|---|

| 髪型 | 胸下のウェーブロング | 胸下のウェーブロング ← **近い** |
| 長さ | 胸下 | 胸下 ← **近い** |

### すでに違う点（これを活かす）

| | 優花(03) | 沙耶(06) |
|---|---|---|
| 前髪 | **あり**（シースルー） | **なし**（深い分け目でかき上げ） |
| 輪郭 | 卵型・やわらかい | スクエア寄りオーバル・顎ラインが強い |
| 目 | 平行二重の丸めアーモンド | 横長で切れ長のアーモンド |
| 年齢 | 25 | 28 |

### 変更案（**沙耶だけを動かす**。優花は変えない）

優花はこのままで問題ないので、**片方だけ動かして差を作る**のが安全です。

| 案 | 内容 | 効果 |
|---|---|---|
| **A（最優先）** | 沙耶を**完全なかき上げ**にする。片側を耳にかけ、**額と眉を完全に出す** | サムネでも「おでこが見える／見えない」で一発で判別できる。最も効く |
| **B（併せて推奨）** | 沙耶の髪を**ワントーン暗いアッシュブラウン**へ（ハイライトは残す） | 色相で分かれる。優花は明るい栗色のまま |
| C（必要なら） | 沙耶を**鎖骨〜胸上**でカットし、ウェーブを大きくゆるくする | 髪の長さでシルエットが変わる。ただし変更が大きい |
| D（味付け） | 沙耶に**シルバーの一粒ピアス**を固定（優花はピアスなし） | 拡大時の識別。サムネには効かない |

**推奨は A ＋ B の2つだけ。** 3つ以上やると顔の印象まで動くので、まずこの2つで見てほしい。

⚠ **顔そのものは変えないでください。** 骨格・輪郭・目・眉・鼻・口・顎・年齢感は
現行の沙耶の顔アップと同一に保つこと。変えるのは**髪型・髪色・小物だけ**です。
